# ED---Menu-personnalisable
Personnalisez le menu latéral d’EcoleDirecte : masquez, organisez et réordonnez instantanément vos entrées.
1. Introduction
L’extension Menu Manager pour EcoleDirecte respecte votre vie privée.Cette politique explique quelles données sont collectées, comment elles sont utilisées et comment elles sont stockées.
Cette extension est indépendante et non affiliée à EcoleDirecte ou Aplim.

2. Données collectées
L’extension ne collecte aucune donnée personnelle.
Aucune information concernant :  

votre identité,  
votre compte EcoleDirecte,  
vos données de navigation,  
vos interactions sur le site,  
ou toute donnée sensible

n’est collectée, transmise ou exploitée.

3. Données stockées localement
L’extension sauvegarde uniquement des préférences locales :  

ordre des menus,  
éléments masqués ou visibles,  
informations techniques nécessaires au fonctionnement.

Ces données sont stockées exclusivement via chrome.storage.sync, c’est‑à‑dire :  

localement dans votre navigateur,  
et éventuellement synchronisées entre vos appareils Chrome (si la synchronisation est activée dans votre compte Google).

Aucune donnée n’est transmise à un serveur tiers.

4. Transmission et partage des données
L’extension ne transmet aucune donnée vers :  

des serveurs externes,  
des services d’analyse,  
des annonceurs,  
ou tout autre tiers.


5. Permissions Chrome
Les permissions demandées servent uniquement à :  

modifier l’affichage du menu d’EcoleDirecte (host_permissions),  
enregistrer vos préférences (storage),  
appliquer les modifications instantanément (scripting, activeTab).

Elles ne servent à aucune collecte ni suivi.

6. Sécurité
L’extension ne traite aucune donnée sensible.Elle ne réalise aucun transfert vers Internet.Le code est visible publiquement si publié via GitHub.
